doot

A terminal emulator for macOS, written in Zig. The VT parser, the cell grid, the scrollback, the glyph atlas and the Metal renderer are written here from scratch.

A goofy little app with serious insides. The name is the sound of the bell — the one that reaches you when an agent needs you.

Download the latest release Apple Silicon. Not yet signed, so macOS will ask once; and until the window is ours it needs brew install sdl3 freetype. Both are on the roadmap, and the page will say when they are done.

What is ours

The rule for the build: link only the platform. Everything else is written here, or is on its way out.

Written hereBorrowed
The VT parser — Paul Williams' DEC state machine, from the paperlibc, for forkpty. The kernel's interface, not a dependency
The cell grid and the scrollback, as rings that rotate instead of movingSDL3, for the window and input — the renderer underneath is already ours, the window is next
The glyph atlas, and the Metal renderer that draws the whole frame in one callFreeType, for rasterizing glyphs — until the rasterizer is ours too
The recorder: every session is an append-only log the terminal can replayNothing else. No framework, no runtime, no telemetry

What it is for

The person at the keyboard is increasingly watching several agents at once, each for minutes to hours, each occasionally needing a human. doot is built for that: which session needs you, what it needs, and the record of everything it did while you were elsewhere.

Every claim in the repository carries a number or a picture. The frame is one draw call; an idle window wakes up zero times a second; and the parser's throughput is below, drawn from the file the benchmark writes rather than typed here.

The numbers

Bytes from a PTY through the parser into the grid — the whole stack below the renderer, on six recorded corpora and two recorded agent sessions. zig build bench writes bench/baseline.txt; this page reads it.
